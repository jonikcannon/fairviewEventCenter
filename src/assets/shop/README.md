# Sale-photo previews

This folder is public: every file under `src/assets` is included in the website build. Add only web-sized, watermarked previews here.

Organize previews by collection:

- `previews/nature/`
- `previews/beach/`
- `previews/hikes/`
- `previews/aerial/`

Use a matching product slug, such as `previews/aerial/coastal-curve.jpg`. Do **not** put full-resolution originals or customer downloads in this folder.
